# Evidências oficiais

Estes conjuntos sustentam o relatório e são somente para consulta na aplicação.
A exclusão do histórico não remove esta pasta. Os dados, gráficos e metadados
foram copiados dos registros originais sem refazer ou alterar medições.

Há quatro coletas CLI em `resultados/` e `meus_resultados/`, além de três tarefas
web selecionadas em `resultados_web/`. Consulte o índice em
[Resultados selecionados](../RESULTADOS_SELECIONADOS.md).

Uma coleta CLI é interrompida e contém somente n=10,11,12 completos. O estado
interrompido permanece explícito: o relatório usa apenas essas amostras completas.
O snapshot web posterior indicado para preservação não integra esta seleção.
